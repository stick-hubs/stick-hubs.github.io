Stick Lab

Make your own games with blocks. Stick Lab is the Stick Hubs version of Scratch: the same editor you know, but faster, in the classic Stick Hubs style, with a stickman to start every project. Projects save as .sl files, which only Stick Lab can open.

▶ Open Stick Lab in your browser

Download Stick Lab

Install Stick Lab on your computer to make games without the internet. Double-click any .sl file and it opens in Stick Lab.

Windows

For Windows 10 and 11. Download stick_lab.exe and open it. Stick Lab installs in a few seconds and adds a desktop shortcut.

Download stick_lab.exe

If Windows says it protected your PC, click More info, then Run anyway. Windows shows this for new apps that aren't paid-signed yet.

Mac

For macOS 12 or newer. Download the zip, open it, and drag Stick Lab.app into your Applications folder.

Mac (Apple chip, M1 and newer)Mac (Intel)

The first time, right-click Stick Lab and choose Open. If your Mac says the app is damaged, open Terminal and run xattr -cr "/Applications/Stick Lab.app", then open it again.

What's different from Scratch

.sl project files

Stick Lab saves projects as .sl files. Only Stick Lab can open them, so your games stay in Stick Lab. It can still open normal Scratch files (.sb3, .sb2 and .sb).

Faster

Stick Lab is built on TurboWarp, which turns your blocks into JavaScript so games run much faster than in normal Scratch.

Classic look

The same layout as Scratch, in Stick Hubs blue, with the Stick Hubs stickman in place of the cat.
